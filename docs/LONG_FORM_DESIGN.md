# Long-Form Pipeline Design (Phase 3)

## Format (recommended initial)
Original commentary/compilation with chapters: "Best moments of [creator] this week/month" with original narration + B-roll + captions. Avoids reused-content monetization risk via substantial original contribution.

## Workflow
1. Topic selection (trend + own analytics).
2. Research + fact check (record sources).
3. Outline (LLM).
4. Script (LLM, dedup/repetition check, fact verification).
5. Narration (edge-tts).
6. Visual sourcing (authorized clips + licensed stock + own footage).
7. Scene planning (scene list with durations).
8. Assembly (segments → concat).
9. Background music + sound design.
10. Captions/subtitles.
11. Thumbnail (Canva).
12. QC (duration >300s, dims, loudness, no black frames, no filler).
13. Human review.
14. Publishing prep.

## Reuse from shorts_studio
transcribe, audio_analysis, scene_detect, edl, renderer (segment concat), qc, thumbnail, music_library, audio_mixer, publishing (dry-run).
